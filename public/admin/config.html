Produtos

Consulta SQL customizada

Caso os produtos não tenham imagem cadastrada no banco, o sistema buscará um arquivo com o ID (ex: 15.jpg, 15.png) nesta pasta.

Opcional. Se preenchida, sua consulta deve retornar os aliases exatos abaixo. Campos obrigatórios precisam estar no SELECT.

Coluna (alias) Tipo Uso Descrição
nome_produto TEXT Obrigatório Nome exibido no card
preco_atual DECIMAL Obrigatório Preço promocional em destaque
id INTEGER Opcional ID do produto — Essencial para a busca de imagens locais por ID
preco_anterior DECIMAL Opcional Preço riscado (de por)
link_imagem TEXT Opcional URL completa ou caminho (ex: https://... ou /imagens/foto.jpg)
data_validade DATE YYYY-MM-DD Opcional Validade simples — exibe badge automática
data_inicio DATE YYYY-MM-DD Opcional Início do período de oferta
data_fim DATE YYYY-MM-DD Opcional Fim do período de oferta
dias_semana TEXT ex: 1,3,5 Opcional Dias válidos: 0=Dom … 6=Sáb, separados por vírgula
hora_inicio TEXT HH:MM Opcional Hora de início da oferta
hora_fim TEXT HH:MM Opcional Hora de término da oferta
texto_validade TEXT Opcional Texto livre para o badge (ex: “SÓ HOJE”). Substitui todas as regras de data/hora.
tipo_promo TEXT Opcional Tipo de promoção: preco_fixo, leva_paga, desconto ou pack (padrão: preco_fixo).
qtd_leva INTEGER Opcional Quantidade total de itens que o cliente leva na promoção Leva e Pague (ex: 3).
qtd_paga INTEGER Opcional Quantidade de itens cobrados na promoção Leva e Pague (ex: 2).
percentual_desconto DECIMAL Opcional Porcentagem de desconto na promoção de Desconto (ex: 10 para 10% OFF).
qtd_minima INTEGER Opcional Quantidade mínima de itens para ativar o desconto (ex: 3).
qtd_pack INTEGER Opcional Quantidade de itens inclusos no pack de preço fixo (ex: 3 por R$ 30,00).
condicao_qty TEXT Opcional Modo da quantidade (Desconto/Pack): a_partir (A partir de) ou a_cada (A cada).
