Hierarquia e Prioridade dos Campos Opcionais

O sistema utiliza as seguintes regras de prioridade para renderizar as informações e badges na tela:

  • 1. Texto de Validade Livre (texto_validade): Tem prioridade máxima. Se preenchido (ex: "SÓ HOJE", "FIM DE SEMANA"), o sistema exibe este texto e ignora todas as outras datas e regras de agendamento.
  • 2. Alerta de Último Dia (data_fim / data_validade): Se a data final do período coincidir exatamente com a data de hoje, o sistema exibe automaticamente o aviso "ÚLTIMO DIA!" para chamar mais atenção do cliente.
  • 3. Agendamento Detalhado (dias_semana e hora_inicio / hora_fim): Se houver restrições de dias ou horários definidos no banco, exibe os respectivos badges (ex: "DIAS: SEG/QUA/SEX" ou "HORÁRIO: 08:00 - 12:00").
  • 4. Contagem Regressiva Simples (data_validade): Se nenhuma das opções acima se aplicar, o sistema calcula os dias restantes para o término e exibe avisos automáticos (ex: "ATÉ AMANHÃ", "ATÉ SÁBADO" ou a data formatada "ATÉ DD/MM").

Layout dos Cards: O campo tipo_promo determina o design visual do card. Os campos específicos de quantidade (qtd_minima, qtd_leva, qtd_pack) só têm efeito se o respectivo layout (desconto, leva_paga, pack, unitario) estiver ativo. O campo condicao_qty é aplicado apenas em desconto e unitario; o tipo pack é sempre um pacote fechado.
